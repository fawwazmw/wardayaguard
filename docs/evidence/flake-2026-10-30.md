# Flake measurement, 2026-10-30

## Command

```bash
npm run test:flake
```

## Scope

- API project: 52 tests.
- Chromium UI project: 28 tests.
- Every test repeated three times with `--repeat-each=3`.
- 81 unique tests, 243 executions.
- One worker, SQLite reset before every test, local server on 4100 and 4173.

## Result

| Metric      | Value                                |
| ----------- | ------------------------------------ |
| Executions  | 234                                  |
| Passed      | 234                                  |
| Failed      | 0                                    |
| Flaky       | 0                                    |
| Duration    | 1.3m                                 |
| Environment | macOS 27, Node 24.18.0, Chromium 156 |

## Interpretation

No test depended on execution order across three consecutive runs, and no test
failed once and passed on a retry. That is a meaningful repeatability check for
a single-worker suite with deterministic data.

This is not a long-term stability number. It does not measure parallel workers,
network latency, cold CI starts, or Firefox and WebKit repeats. The nightly
matrix is the long-term signal for browser coverage.

## How to reproduce

```bash
npx playwright install chromium
npm run test:flake
```

The command writes the usual HTML report. It overwrites the previous report, so
run it after, not before, a report you want to keep.
